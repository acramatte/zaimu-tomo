  ## Nits
  
  ### 8. Cascade counts need a lock
  - **Dimension:** decision 5.
  - **Risk:** the worker takes the document lock before appending (ocr_worker.ex:214). If `delete_document` counts children without that lock, an extraction can commit between the count and the cascade, and the event understates what was deleted.
  - **Mitigation:** lock the document `FOR UPDATE` first in the delete transaction.
  - **Counter-argument:** the race needs a delete during the final moment of OCR for a single user.
  
  ### 9. Diff semantics are undefined
  - **Dimension:** field diffs.
  - **Risk:** `post_entry` diffs against a struct held in LiveView assigns (show.ex:784), so a before-value can be stale. A save with no changes performs no update, but decision 9 still implies an event.
  - **Mitigation:** load the row inside the transaction for diffed updates, and state whether no-op saves write nothing.
  - **Counter-argument:** one user rarely has two tabs racing, and stale before-values are low impact.
